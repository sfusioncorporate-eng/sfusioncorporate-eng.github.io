# sfusioncorporate-eng.github.io

## Журнал «Гео Неважно»

Статический сайт и полнотекстовая RSS-лента для Дзена. Публикация: GitHub Pages, ветка main.

### Редакционные источники

- content/new-articles.json, more-articles.json, final-articles.json: девять новых материалов, по четыре блока с отдельными иллюстрациями.
- content/original-item.xml: исходный материал со стабильными GUID и датой.
- content/publication-dates.json: реальные даты первой публикации; повторная сборка их не меняет.
- assets/articles/: самостоятельные изображения блоков, JPEG.

### Сборка и проверка

Нужны Python, Pillow и lxml.

    python build.py
    python validate.py
    python validate.py --live

Проверка требует 10 материалов, полный текст RSS, соответствие тексту страниц, 41 уникальное изображение, корректные размеры и доступное подтверждение домена. Режим --live проверяет публичные адреса и сравнивает опубликованные файлы с локальными. Отчёт: content/validation-report.json.

Статус на 12 октября 2026: пакет подготовлен для повторной проверки RSS. Одобрение и импорт Дзена не подтверждены. Расписание двух публикаций в день ещё не включено.

Публичная версия проверена 12 октября 2026: 10 материалов, 41 изображение, 57 адресов возвращают HTTP 200 и совпадают с подготовленными файлами. Снимок главной страницы: content/site-review.jpg. В браузере проверены четыре блока и четыре загруженных изображения новой статьи. Проверка на стороне Дзена ещё не пройдена.
